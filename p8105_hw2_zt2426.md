# Problem 1

## Import and clean the subway data

``` r
subway <- read_csv(
  "data/subway.csv",
  show_col_types = FALSE
) %>%
  janitor::clean_names() %>%
  select(
    line, station_name, station_latitude, station_longitude,
    starts_with("route"), entry, vending, entrance_type, ada
  ) %>%
  mutate(
    entry = entry == "YES",
    across(starts_with("route"), as.character)
  )

dim(subway)
```

    ## [1] 1868   19

Each row describes a subway entrance or exit. The data include the line,
station name, station coordinates, routes served, entry permission,
vending, entrance type, and ADA compliance. I cleaned the column names,
kept the requested variables, and changed entry from YES/NO to
TRUE/FALSE. I also made all route columns character variables so they
can be combined later. The cleaned data have 1868 rows and 19 columns.
These data are not yet tidy because route names are spread across
several columns.

## Import and clean the baseline data

``` r
baseline_raw <- read_csv(
  "data/mci_baseline.csv",
  skip = 1,
  na = c("", "NA", "."),
  show_col_types = FALSE
) %>%
  janitor::clean_names() %>%
  rename(baseline_age = current_age) %>%
  mutate(
    sex = factor(sex, levels = c(0, 1), labels = c("Female", "Male")),
    apoe4 = factor(
      apoe4,
      levels = c(0, 1),
      labels = c("Non-carrier", "Carrier")
    )
  )

baseline <- baseline_raw %>%
  filter(is.na(age_at_onset) | age_at_onset > baseline_age)

women <- baseline %>%
  filter(sex == "Female")

baseline_summary <- tibble(
  recruited = nrow(baseline_raw),
  eligible = nrow(baseline),
  excluded = nrow(baseline_raw) - nrow(baseline),
  developed_mci = sum(!is.na(baseline$age_at_onset)),
  mean_baseline_age = mean(baseline$baseline_age),
  women_apoe4_proportion = mean(women$apoe4 == "Carrier")
)

knitr::kable(baseline_summary, digits = 4)
```

| recruited | eligible | excluded | developed_mci | mean_baseline_age | women_apoe4_proportion |
|---:|---:|---:|---:|---:|---:|
| 483 | 479 | 4 | 93 | 65.0286 | 0.3 |

The first row of the CSV contains descriptions rather than column names,
so I skipped it. A dot in age_at_onset means missing, so I read it as
NA. I cleaned the variable names and changed sex and APOE4 status to
factors with labels. Each row represents one participant. I excluded
people whose MCI onset age was less than or equal to their baseline age,
and kept people with missing onset age because they stayed MCI free
during follow-up.

The original file contains 483 recruited participants. After excluding 4
people who already had MCI at baseline, 479 participants remain. Among
these, 93 developed MCI during follow-up. Their average baseline age is
65.03 years. Among the 210 women in the eligible sample, 63 are APOE4
carriers, a proportion of 0.3 (30%).
