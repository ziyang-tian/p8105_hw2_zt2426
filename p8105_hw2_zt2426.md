## Import and clean the subway data

``` r
subway <- read_csv(
  "data/subway.csv",
  show_col_types = FALSE
) %>%

    line, station_name, station_latitude, station_longitude,
    starts_with("route"), entry, vending, entrance_type, ada

    entry = entry == "YES",
    across(starts_with("route"), as.character)

```

Each row is one subway entrance or exit. The dataset includes the line,
station name, latitude and longitude, train routes, whether entry is
allowed, whether vending is available, entrance type, and ADA
compliance. I first cleaned the column names and kept the variables
needed for this question. Then I changed entry from YES/NO to
TRUE/FALSE, so it is a logical variable. I also changed all route
columns to character so I can combine them later. After cleaning, the
dataset has 1868 rows and 19 columns. The data are not tidy yet because
the routes are in separate columns.

## Import and clean the baseline data

``` r
baseline_raw <- read_csv(
  "data/mci_baseline.csv",
  skip = 1,
  na = c("", "NA", "."),
  show_col_types = FALSE

  developed_mci = sum(!is.na(baseline$age_at_onset)),
```

I skipped the first row because it contains descriptions. The second row
contains the column names. I treated dots in age_at_onset as NA and
cleaned the column names. I changed sex to Female or Male and APOE4
status to Carrier or Non-carrier, and stored both as factors. Each row
is one participant. I removed people whose MCI onset age was at or

the file says they did not develop MCI during follow-up.

There are 483 participants in the original baseline file. I removed 4
